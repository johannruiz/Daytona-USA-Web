# Changelog

## Community preview — unreleased

- Real WebAssembly game engine with WebGPU 3D rendering and original CPU tile composition.
- English arcade-style ROM import modal with a user-supplied transparent logo.
- Enhanced by default: native window resolution, widescreen camera and draw distance +1.
- Classic preserves original resolution, aspect ratio and draw distance.
- Fresh Single / Export settings and zero credits; existing NVRAM preserved.
- Keyboard, standard gamepad and multitouch phone controls with arcade settings access.
- Portrait preserves the full HUD; landscape uses the wider camera.
- Subtle FPS counter; no visible game-frame counter.
- Source-only community documentation and issue templates.

No public stable release or physical-phone support certification has been made.

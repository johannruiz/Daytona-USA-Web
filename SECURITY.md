# Security reporting

The ROM importer processes user-selected files. This preview has not received a security audit. Use local files from sources you trust and serve the app through localhost or HTTPS. This repository does not include a backend, telemetry service or ROM-upload endpoint.

For a suspected vulnerability, use GitHub's private vulnerability reporting if the repository owner has enabled it. If it is unavailable, ask the owner for a private contact without posting exploit details publicly. No private reporting address has been configured in this source package.

Include the affected revision, browser/OS, minimal reproduction description and impact. Do not attach game ROMs, credentials or private data. Public issue templates are for ordinary compatibility and gameplay reports.
